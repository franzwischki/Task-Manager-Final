Task Manager
A full-stack task management application that lets you add, complete, and delete tasks.
Technologies Used

Next.js
Node.js

Getting Started
Run the development server:
npm run dev
Open http://localhost:3000 in your browser to see the app.
Features

Add new tasks
Mark tasks as complete
Delete tasks

What I Learned
Building this project gave me a much better understanding of how full-stack applications work. Using Node.js on the back end and Next.js on the front end showed me how the two sides of an app communicate with each other. It was the most complete project I built this semester.
